#  Dashboard de Análisis de Datos

##  Descripción

Este proyecto consiste en un dashboard desarrollado en Python que permite visualizar datos de forma gráfica.

##  Problema

Los datos en Excel no permiten visualización en tiempo real.

##  Solución

Se desarrolló un dashboard interactivo que muestra datos mediante gráficos.

##  Arquitectura

* Backend: Python
* Frontend: HTML, CSS, JavaScript
* Base de datos: MySQL

##  Requerimientos

* Python 3
* Librerías: flask, pandas

##  Instalación

1. Descargar repositorio
2. Ejecutar:
   python dashboard.py

##  Configuración

Configurar base de datos en el código

##  Uso

* Visualizar datos
* Analizar información
